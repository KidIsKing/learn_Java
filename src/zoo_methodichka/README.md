# Методичка: наследование и полиморфизм в Java

Пакет `zoo_methodichka` повторяет идею вашего пакета `zoo`, но каждый шаг оформлен так, чтобы его можно было изучать без видео.

## Как запустить

Из корня проекта:

```powershell
javac -encoding UTF-8 -d bin src/zoo_methodichka/*.java
java -cp bin zoo_methodichka.Main
```

Или запустите `Main.java` через кнопку запуска в VS Code.

## 1. Пакет

В начале каждого файла написано:

```java
package zoo_methodichka;
```

Пакет группирует связанные классы. Папка и имя пакета должны совпадать: файлы находятся в `src/zoo_methodichka`, поэтому пакет называется `zoo_methodichka`.

## 2. String: строки

`String` хранит текст. Строку можно создать через литерал:

```java
String language = "Java";
```

Полезные методы:

```java
language.length();       // длина: 4
language.charAt(0);      // первый символ: J
language.toUpperCase();  // JAVA
language.contains("av"); // true
language.replace("Java", "Java 21");
```

Для сравнения текста используйте `equals`, а не `==`:

```java
String first = new String("Java");
String second = "Java";
System.out.println(first.equals(second)); // true: одинаковый текст
System.out.println(first == second);      // false: разные ссылки
```

`String` неизменяемый. Метод `replace` не меняет исходную строку, а возвращает новую:

```java
String oldText = "Java";
String newText = oldText.replace("Java", "Java 21");
```

В `Main` найдите метод `stringExamples` и измените его примеры.

## 3. Класс и объект

Класс - это описание объекта. Объект создаётся оператором `new`:

```java
Dog dog = new Dog("Бобик", 5, 18.5);
```

Здесь `Dog` - тип, `dog` - ссылка на объект, а `new Dog(...)` вызывает конструктор.

## 4. Конструктор

Конструктор имеет имя класса и не имеет типа результата:

```java
public Dog(String name, int age, double weight) {
    super(name, age, weight);
}
```

`super(...)` вызывает конструктор родителя `Animal`. Он должен быть вызван до работы с частью объекта, принадлежащей родителю.

## 5. Абстрактный класс

`Animal` объявлен как `abstract`. Это общий шаблон: у всех животных есть имя, возраст и вес, но конкретная еда и сон отличаются.

```java
public abstract class Animal {
    public abstract void eat();
}
```

Абстрактный метод не имеет тела. Каждый обычный наследник обязан его реализовать. Поэтому нельзя написать `new Animal()`.

## 6. Наследование

```java
public class Dog extends Animal
```

`Dog` получает доступное поведение `Animal` и добавляет своё. Java поддерживает наследование от одного класса.

## 7. Переопределение и `@Override`

```java
@Override
public void eat() {
    System.out.println("Бобик ест корм");
}
```

Переопределение означает: наследник заменяет реализацию метода родителя. `@Override` помогает компилятору проверить, что метод действительно существует у родителя.

## 8. Интерфейс

`LivingBeing` описывает способность объекта:

```java
public interface LivingBeing {
    void be();
}
```

Класс подключает интерфейс словом `implements`. Один класс может реализовать несколько интерфейсов:

```java
public class Animal implements LivingBeing
```

Интерфейс отвечает на вопрос «что объект умеет», а наследование отвечает на вопрос «к какому общему виду он относится».

## 9. Полиморфизм

```java
Animal animal = new Dog("Рекс", 2, 12.0);
animal.eat();
```

Слева указан общий тип ссылки `Animal`, справа создан конкретный `Dog`. При вызове Java выбирает реализацию по настоящему типу объекта, поэтому сработает `Dog.eat()`.

Это позволяет обрабатывать разные виды одинаково:

```java
Animal[] animals = {dog, cat, monkey};
for (Animal animal : animals) {
    animal.eat();
}
```

## 10. Инкапсуляция

Поля `name`, `age` и `weight` закрыты модификатором `private`. Изменять их можно через методы:

```java
dog.setWeight(19.0);
System.out.println(dog.getWeight());
```

В `setWeight` находится проверка. Благодаря этому объект нельзя случайно перевести в некорректное состояние.

## 11. `this`, `super` и `private`

- `this` означает текущий объект;
- `super` обращается к родительской части объекта;
- `private` доступен только внутри своего класса;
- `protected` доступен классу и его наследникам;
- `public` доступен из любого пакета.

Попробуйте в конструкторе написать `this.name = name`: слева поле объекта, справа параметр конструктора.

## 12. switch

`switch` выбирает один вариант из нескольких. В современном варианте используется стрелка `->`:

```java
String sound = switch (animalType) {
    case "собака" -> "гав-гав";
    case "кошка" -> "мяу";
    default -> "неизвестный звук";
};
```

Здесь `switch` возвращает значение, поэтому результат можно сразу записать в переменную. `break` не нужен.

Классический вариант использует двоеточие и `break`:

```java
switch (menuNumber) {
    case 1:
        System.out.println("Создать");
        break;
    case 2:
        System.out.println("Показать");
        break;
    default:
        System.out.println("Неизвестный пункт");
}
```

Без `break` выполнение может перейти в следующий `case`. Это называется проваливанием (`fall-through`).

## 13. static

`static` означает, что поле или метод принадлежит классу целиком, а не отдельному объекту.

В `Animal` есть общий счётчик:

```java
private static int animalCount;
```

Каждый конструктор увеличивает его. Получаем значение через имя класса:

```java
System.out.println(Animal.getAnimalCount());
```

Статический метод можно вызвать без создания объекта. Поэтому внутри `static`-метода нельзя напрямую использовать нестатические поля вроде `name`: непонятно, объект какого животного брать.

Пример:

```java
public static String category() {
    return "Животное";
}
```

Вызывать так:

```java
Animal.category();
```

Обычные поля (`name`, `age`, `weight`) у каждого объекта свои, а `animalCount` один на весь класс.

## 14. Приведение типа

Если ссылка имеет общий тип, но объект конкретный, можно проверить тип:

```java
if (animal instanceof Dog dogFromAnimal) {
    dogFromAnimal.bark();
}
```

Проверка нужна, потому что у типа `Animal` метода `bark()` нет.

## Порядок изучения

1. Запустите `Main` и прочитайте вывод.
2. Измените строки в `stringExamples`: проверьте `length`, `substring`, `startsWith`.
3. Передайте в `switchExamples` значения `"кошка"` и `"обезьяна"`.
4. Создайте ещё два объекта и проверьте, как меняется `Animal.getAnimalCount()`.
5. Измените имена, возраст и вес животных.
6. Добавьте метод `run()` в `Dog`.
7. Добавьте новый класс `Bird extends Animal` и реализуйте `eat()` и `sleep()`.
8. Добавьте в интерфейс `LivingBeing` метод `move()` и исправьте все классы.
9. Попробуйте передать массив `Animal[]` в отдельный метод `feedAll(Animal[] animals)`.
10. Раскомментируйте ошибочные строки по одной и прочитайте сообщение компилятора.

## Главное различие

```java
Dog dog = new Dog(...);
```

У ссылки тип `Dog`, поэтому доступны `eat()`, `sleep()` и `bark()`.

```java
Animal dog = new Dog(...);
```

У ссылки тип `Animal`, поэтому доступны только методы `Animal`, но переопределённые методы всё равно выполняются из `Dog`. Это и есть основа полиморфизма.
